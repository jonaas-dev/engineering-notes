# Frontend

Notes on the browser side, weighted towards the things that outlive a framework: what the
platform actually does, and what you cannot hide in a bundle.

## Notes

- [Securing API keys in a React app](securing-api-keys.md) — nothing you send to the frontend
  is hidden, all environment variables are equal, and what to do instead.
- [You Don't Need a Build Step](you-dont-need-a-build-step.md) — how building became the
  default, and how much of it the platform has since absorbed.
- [The web's next transition](the-webs-next-transition.md) — MPAs, progressively enhanced
  MPAs, SPAs and what comes after, compared across persistence, routing, fetching, mutation,
  rendering and feedback.
- [History of web browser engines](history-of-web-browser-engines.md) `[CA]` — which engines
  are still alive and which are not, from Lynx to Blink.
- [Los 7 mejores libros para aprender JavaScript](los-7-mejores-libros-para-aprender-javascript.md)
  `[ES]` — the reading list, from *You Don't Know JS* to *Learning JavaScript Design Patterns*.
